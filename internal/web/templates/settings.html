Nostr identity

This is the app's own key, not yours. BrollyZapper made it on first run and you do not normally touch it. It signs every zap receipt and is announced as nostrPubkey in the lightning address response, so senders' clients use it to recognise receipts as coming from this address. You are identified as the recipient by the zap request itself, which is a different thing.

The field below is for continuity: restoring a backup that lost the database, moving to a new box, or rebuilding an install whose address is already published. Import the key that install used and receipts you have already published stay verifiable. Replacing it with anything else means those receipts stay signed by the old key.

Do not paste your personal nostr key. It would put a key that can post, DM and delete as you inside the part of this app that faces the network, and it would gain you nothing — a receipt-signing key is worth nothing to an attacker, and a zap receipt does not claim to be from you personally.
